10 頁無雜訊顧問式網頁簡報。每頁採一個結論、重點數字與相關圖像；原簡報紅圈另提供下載。

## 資料與公開範圍

- 唯一機會清單：`機會清單_20261005.xlsx`。
- 原簡報：`南區預算20261005.pptx`。
- 審閱日：2026-10-06。這是決策討論稿，不是核定財務預算。
- 使用者已確認以 GitHub 帳號 `davidyeh51` 新增網站並完整公開。
- **不發布原始 XLSX 或原始 PPTX**；僅發布本次整理的簡報、審閱摘要及圈註副本。原始檔保留不改。
- 10.4658 億為沿用原簡報的勝率加權商機，不能直接當 2027 可認列營收；所有情境假設已標記。

## 使用

直接開啟 `index.html`，或部署根目錄至 GitHub Pages；沒有套件、CDN、追蹤程式或外部執行期依賴。

- 左右方向鍵／PageUp、PageDown 翻頁；Home、End 跳至首尾。
- 觸控左右滑動翻頁；目錄可跳頁；網址 `#slide-5` 可分享指定頁。
- 「資料與下載」提供原始數據證據索引、PDF、PPTX、完整摘要與圖片授權。
- 瀏覽器列印顯示完整 10 頁，16:9；PPTX 為保真圖像版，逐項文字／版面修改以 HTML、CSS 為準。

## 檔案

- `index.html`：簡報內容與證據／授權對話框。
- `styles.css`：顧問簡報版型與印刷樣式。
- `app.js`：翻頁、目錄、全螢幕、觸控與列印。
- `assets/`：本地圖片與逐圖授權 `image-credits.json`。
- `downloads/`：PDF／PPTX 與詳細審閱稿。
